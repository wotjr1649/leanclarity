# blog

Post records and their public URLs. Stdlib only.

- `app/util/text.py` — shared text helpers (`slugify`, `truncate`)
- `app/posts.py` — post records and URL building
- `tests/test_text.py` — `python tests/test_text.py`

Text handling shared by more than one module lives in `app/util/text.py`.

No dependencies.
